# Qadam — история шага

Веб-интерфейс ИИ-помощника для врача: сравнивает походку ребёнка с ДЦП в трёх условиях —
обычная ходьба (**Baseline**), словесная подсказка (**Verbal**) и виртуальная реальность (**VR**).

Хакатон AI-Sana Shakarim Solveathon: AI & Medicine-2026, школьный трек.

> Это вспомогательный инструмент, не диагноз. Решение принимает врач.

## Приватность

Все файлы читаются прямо в браузере и **никуда не отправляются**. Сервера с данными нет.
Датасет в репозиторий не входит (папка `data/`, `*.csv`, `*.zip` в `.gitignore`).

## Как запустить

Нужен только Python 3 (Node и сборка не нужны).

```bash
cd solveathon
python3 -m http.server 8000
```

Откройте http://localhost:8000 и перетащите в окно:

1. шесть CSV-файлов датасета: `Discrete_Parameters_{Baseline,Verbal,VR}.csv` и `Kinematics_Kinetics_{Baseline,Verbal,VR}.csv`;
2. по желанию — `ai_results.json` с заключением модели (для проверки подойдёт `mock_ai.json`).

Условие определяется по названию файла (`Baseline`, `Verbal`, `VR`), тип файла — по столбцам.
Формат CSV: разделитель `;`, десятичный разделитель `,`, пропуски — `NaN` или пустая ячейка.

## Деплой на Vercel

Это статический сайт: Vercel → New Project → импортировать репозиторий → Framework: **Other**,
Build Command — пусто, Output Directory — корень. Никаких переменных окружения не нужно.

## Qadam Live — трекинг по камере

Страница `live.html` (ссылка «Qadam Live» в шапке) измеряет углы бедра и колена по веб-камере или видеофайлу.
**Трекинг сделан участником нашей команды на [MediaPipe](https://ai.google.dev/edge/mediapipe) от Google**
(Pose, Hand и Face Landmarker, `@mediapipe/tasks-vision` 0.10.21). Мы перенесли его в дизайн сайта
и добавили казахский язык; расчёт углов и работа моделей остались как в оригинале.

- Видео **никуда не отправляется**: модели скачиваются один раз, кадры обрабатываются в браузере.
- Камера работает только по `https://` (Vercel) или `http://localhost`, не при открытии файла двойным кликом.
- Углы считаются по двумерному изображению: ребёнок идёт боком к камере, ноги видны целиком.
  Это ориентир для врача, не замена лабораторному анализу.

## Формат `ai_results.json`

Файл делает участник команды, который обучает модель. Интерфейс просто показывает его содержимое.
**Любое поле можно не указывать — тогда соответствующий блок на экране не показывается.**
Обязателен только объект `participants`.

```json
{
  "model": {
    "name": "Gradient Boosting",
    "metric": "accuracy",
    "value": 0.82,
    "validation": "GroupKFold по subject"
  },
  "participants": {
    "s61520_19": {
      "best_condition": "VR",
      "significant_changes": [
        { "parameter": "GVS_aSagK", "condition": "VR", "change_pct": -18.2, "p_value": 0.004 }
      ],
      "unstable_cycles": [
        { "condition": "Verbal", "cycle": 7, "reason": "Резкий рост отклонения в тазу" }
      ],
      "summary_ru": "Текст для врача на русском.",
      "summary_kz": "Дәрігерге арналған мәтін."
    }
  }
}
```

### Поля

| Поле | Тип | Что показывается |
|---|---|---|
| `model.name` | строка | название модели в шапке блока |
| `model.metric`, `model.value` | строка, число 0–1 | качество модели, например «accuracy 0,82» |
| `model.validation` | строка | как проверяли модель (должно быть разбиение **по subject**) |
| `participants` | объект | ключ — ID участника **точно как в CSV** (`s61520_19`) |
| `best_condition` | `"Baseline"` / `"Verbal"` / `"VR"` | крупная строка «Лучшее условие» и метка на развороте |
| `significant_changes[]` | список | таблица значимых изменений |
| `…parameter` | строка | название столбца CSV (`GPS_a`, `GVS_aSagK`, …) — переводится на язык интерфейса |
| `…condition` | строка | условие, в котором изменение |
| `…change_pct` | число | изменение к Baseline в %: минус = значение уменьшилось |
| `…p_value` | число | p-value; меньше 0,001 показывается как «p < 0,001» |
| `unstable_cycles[]` | список | список нестабильных шагов и их число на развороте |
| `…condition` | строка | условие |
| `…cycle` | число | номер цикла **с 1**, в порядке строк CSV для этого участника и условия |
| `…reason` | строка | почему шаг нестабильный |
| `summary_ru`, `summary_kz` | строка | текст заключения; если нет текста на выбранном языке, показывается другой с пометкой |

### Цвет изменений

Зелёный «лучше» / красный «хуже» ставится только там, где направление клинически однозначно:
у `GPS_a` и всех `GVS_*` меньше = ближе к норме. У `aMinSagH` и `pctmZeroStSagH` цвет нейтральный.

### Если файл неправильный

- не JSON → «не удалось прочитать JSON»;
- нет `participants` → «в JSON нет раздела participants»;
- участника нет в файле → «нет заключения для этого участника».

Ранее загруженное заключение при ошибке не стирается.
